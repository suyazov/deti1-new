# deti1.ru /2 — визуальная preview-версия

Отдельная статическая версия сайта для визуальной приёмки нового направления. Она не заменяет корневой `deti1.ru/`, не индексируется и разворачивается только в `/var/www/deti1.ru/2`.

- Контент: B2B-франшиза / запуск под собственным брендом / документы.
- Калькулятор: формула, коэффициенты, defaults и диапазоны повторяют `src/components/ProfitCalculator.tsx`; доступен без формы.
- Цены: рабочая baseline-матрица, не новая публичная оферта.
- Маскоты: новое направление для `/2`; финальная замена основной страницы всё ещё требует отдельной визуальной приёмки.
- Внешние контакты: WhatsApp, Telegram, телефон; реальная форма `/api/send.php` в этой preview не используется.

Production `/2` требует отдельной точной authority, backup nginx и существующего `/2`, `nginx -t`, reload и live desktop/mobile/readback. Корневые файлы сайта не перезаписывать.
