# Контекст проекта — Дети в приоритете

Дата консолидации: 25.09.2026. Канонический вход в проект. В рабочей ветке документация является кандидатом; принятие устанавливается по PR, exact-head проверкам, независимому разбору и merge. На main используется принятая версия, а не отдельный архив из чата.

## Назначение и аудитория

Владелец — Артём. Лицо продукта и принимающая сторона по визуальному стилю — Анна Суязова. `deti1.ru` представляет франшизу и помощь предпринимателю в открытии/развитии частного сада.

Бизнес-результат: посетитель понимает продукт, бюджет/условия, основания доверять команде и следующий шаг обращения. «Сайт сейчас не продающий» — оценка владельца; конверсия и причины потерь количественно здесь не измерены.

Ситуации посетителя: открывает первый сад; переводит центр в формат сада; развивает действующий бизнес; запускается самостоятельно с материалами. Не смешивать сайт с `lk.deti1.ru`, Kids CRM или SY3 SaaS Platform.

## Принятые ограничения и неизвестное

Решения владельца — [DECISIONS](DECISIONS.md). Калькулятор сохраняется; новые зверюшки выбираются по конкретным изображениям; коммерческая доработка сохраняет тёплый характер бренда. Цены, содержание и статусы — [CONTENT_MODEL](CONTENT_MODEL.md), а не память или разрозненные предложения.

Не установлены: финальный актуальный публичный прайс, аудированные показатели отдельных филиалов, подтверждение части наград/маркетинговых метрик, итоговые зверюшки, реальная доставка формы и выдача презентации. Эти пробелы не мешают прототипу, но ограничивают публичный релиз соответствующих обещаний.

DETI-01 уже установил точную базу live/source: активный document root — `/var/www/deti1.ru`; production не byte-identical текущему main; Hero различается по компоновке и тексту, при этом выборка H1/H2/H3 после Hero совпала. Причина drift не доказана. Подробности — [SOURCES](SOURCES.md), S-08.

## Текущая задача

**Задача:** собрать и опубликовать отдельную визуальную preview-версию по точному адресу `deti1.ru/2` на основе одобренного владельцем макета. Работа выполняется напрямую без Bridge; корневая версия `/` остаётся без изменений.

**Результат-кандидат:** автономная статическая `/2` с новым hero, новыми SVG-зверюшками, карточками трёх форматов, сохранённой математикой калькулятора, этапами работы, блоком Анны и контактами. `/2` помечена `noindex`; форма `/api/send.php` не используется.

**Текущее состояние:** владелец дал точное разрешение на публикацию `/2`. Перед выпуском требуется exact-head проверка, независимое review, merge, backup nginx/существующего `/2`, `nginx -t`, контролируемый reload и live desktop/mobile/calculator readback. DNS, секреты, корневой сайт и другие каталоги не входят в разрешение.

**Следующее действие:** принять exact-head PR, развернуть только содержимое `preview-v2/` в `/var/www/deti1.ru/2`, добавить минимальные nginx locations для `/2`/`/2/`, проверить `noindex`, статические ассеты, отсутствие horizontal overflow и совпадение контрольных расчётов. Финальная замена `/` остаётся отдельным решением.
